# Roadmap — Second Brain Operator Launch (Steving Felix)

> **How to use in Trello:** Each `## Phase` = a List (column). Each `### Card` = a card.
> Each **Checklist** = a checklist on the card; items are *outcomes*, not micro-steps —
> the small details live inside each item. Sub-checklists only where a chunk genuinely splits in two.
> Work the phases in order: **proof before polish.**

---

## The Roadmap at a Glance

| Phase | Outcome (what "done" means) |
|---|---|
| **0 · Foundation** | A locked, defensible message and a clear offer |
| **1 · Proof** | Real, named proof that backs the premium positioning |
| **2 · Page Ready** | A live, shareable page with a working application flow |
| **3 · Pre-Launch** | Content + operations ready to receive and convert interest |
| **4 · Launch** | Public, with momentum |
| **5 · Grow & Scale** | Iterate on results, document the method, prep course/network |

---

## Phase 0 · Foundation

### Card: Positioning & Message
- [ ] Lock the category claim + headline — lead with the real differentiator (**pushback / challenges your thinking**)
- [ ] Phrase "Second Brain" so it rides the existing wave without claiming you invented it (own *Operator*)
- [ ] Audit every claim on the page: provable vs. aspirational — keep only what survives a sharp client

### Card: Offer & Pricing
- [ ] Define the three tiers — Sprint, Contract, Retainer — each with scope + price
- [ ] Set payment terms, invoicing tool, and working boundaries (hours, response time, out-of-scope)
- [ ] Define your ideal client + the "not for you if…" filter

---

## Phase 1 · Proof  *(most important — do this first)*

### Card: Real Proof
- [ ] Get permission + real testimonials from both clients (named, or role + a verifiable specific)
- [ ] Build one strong case study: what was stuck → what you did → the result, with real specifics
- [ ] Reframe or drop "100% retention" — say it plainly instead ("two clients, both still here")

### Card: Personal Brand Assets
- [ ] Real photo + a short, human About paragraph (replaces the SF monogram)
- [ ] Lock domain, professional email, and consistent social handles

---

## Phase 2 · Page Ready

### Card: Make the Page Credible
- [ ] Swap in real testimonials + photo, and fix the details (© year, availability numbers)
- [ ] Make it share-ready — link previews, meta tags, favicon (so the link looks premium on X/LinkedIn)

### Card: Application Flow
- [ ] Replace the mailto with a real application form that qualifies leads
- [ ] Write your review criteria so "selective / not every inquiry accepted" is actually true

### Card: Go-Live Setup
- [ ] Domain + email + hosting/deploy + analytics
- [ ] Full QA — mobile, every link, proofread, and a cold review from 2 people

---

## Phase 3 · Pre-Launch

### Card: Launch Content
- [ ] Write the founder-story launch posts for X + LinkedIn (did it by hand → 2 clients → the role)
- [ ] Build a small content bank + a warm-outreach DM template

### Card: Operational Readiness
- [ ] Booking link + discovery-call script ready
- [ ] Proposal/contract + client onboarding templates ready

---

## Phase 4 · Launch

### Card: Go Public
- [ ] Publish the page + post the launch story across channels
- [ ] Warm-DM your target list (5–10 fitting people)
- [ ] Engage daily through launch week + note which angle lands hardest

---

## Phase 5 · Grow & Scale

### Card: Measure & Iterate
- [ ] Track applications + conversion, fix the weak points, fill the open retainer spot

### Card: Document the Method
- [ ] Capture your system — intake, holding context, pushing back, execution (this is the future course)
- [ ] Outline a course/cohort, but validate demand (waitlist) before building it

### Card: Scale (later)
- [ ] Decide what leads when proof is undeniable: the course or the operator network
